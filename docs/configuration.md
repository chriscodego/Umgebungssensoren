# Konfiguration

| Was | Wert |
|---|---|
| Serieller Port | automatisch (USB-VID 0x2341); sonst `--port COM9` oder Umgebungsvariable `UMWELT_PORT=COM9` |
| Messprotokoll (CSV) | Standard `~/umwelt_messwerte.csv` (außerhalb des Repos, lokal; Aufbewahrung entscheidet der Nutzer) |
| arduino-cli | `C:\Program Files\Arduino CLI\arduino-cli.exe` (nicht im PATH) |

Weitere Einstellungen (Intervall, Schwellwerte, Einheiten) folgen mit der Spec/`SPEC.md`.
